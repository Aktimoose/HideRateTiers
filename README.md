# Hide Rate Tiers
Normalizes the rate tiers displayed for every level.

By default it hides all rate tiers, but you can also change it so every level is featured, epic, legendary, or mythic.

If you only want this to affect levels that are actually rated, enable the "Only Rated Levels" setting. Unrated levels will then keep their normal appearance.

This does not hide whether a level is rated in general, as the star rating is still visible.
